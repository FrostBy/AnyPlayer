# Any Player0.1.0-dev.13

Windows x64 preview for IntelliJ Platform2026.1 (261).

- Video/audio playback, direct HTTP(S) and local media opening, images and seekable animations.
- Live/full-file source spectrograms, waveform navigation with separate channels, and MediaInfo reports.
- Smooth source-clock presentation and buffered waveform Follow.
- Main-video seek frames retain display quality; tiny hover previews stay in the popup.
- Original screenshots and GPLv3 source with retained dependency notices.

Validation:52 JUnit/SDK checks and15 native integration checks passed. Plugin Verifier reports compatibility with IU-261.22158.277. The owner accepted the playback result. Other native platforms/products are not yet verified.
