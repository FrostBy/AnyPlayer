# Any Player 0.1.0

Video player, audio player and image viewer for JetBrains IDEs.

## Included

- Video and audio playback with seeking, speed, volume and track selection.
- Direct HTTP(S) media and local paths, including explicit transport-stream and extensionless files.
- Images with Fit, original-pixel inspection, zoom and pan; seekable GIF/APNG/WebP animation.
- Live/full-file source spectrograms, buffered waveform Follow and separate channels.
- MediaInfo reports with copyable properties.
- Smooth source-time cursors and display-quality seek frames, without enlarging tiny hover previews into the video.

## Download

`AnyPlayer-0.1.0-windows-x86_64.zip` is the installation package for Windows x64 and IntelliJ Platform 2026.1 (261). Install through Settings → Plugins → Install Plugin from Disk, then restart.

Other OS/CPU packages are being prepared and will be added to this release after their checks. Do not use the Windows archive on macOS, Linux or ARM64 IDE processes.
