# Any Player 0.1.0

Video player, audio player and image viewer for JetBrains IDEs with a minimum of IntelliJ Platform 2026.1 (261).

Plugin ID: **`me.romanovsky.anyplayer`**. Remove an earlier development installation before switching to this identity.

## Included

- Video/audio playback with seeking, speed, volume and track selection.
- Local paths and direct HTTP(S) media URLs, including explicit transport-stream and extensionless opening.
- Images with Fit, original-pixel inspection, zoom/pan and seekable GIF/APNG/WebP animation.
- Live/full-file spectrograms with stable buffered edges, waveform Follow and separate channels.
- Timestamped hover previews, frame stepping, display-quality scrub frames and replay after EOF.
- MediaInfo properties and copyable reports.

## Compatibility

The installers declare `since-build="261"` and omit `until-build` and `strict-until-build`. This removes the former 261-only ceiling; it does not claim that every future IDE has been tested. See `BUILD-INFO.json` and the validation record for the exact checked builds.

## Downloads

Separate self-contained installation ZIPs are available for **Windows, macOS and Linux**, each on **x86_64 and ARM64**. Choose the running IDE's OS/architecture. Install through **Settings > Plugins > Install Plugin from Disk**, then restart.

All packages belong to this release. A universal ZIP is not required. `SHA256SUMS.txt` covers installers and source bundles; `BUILD-INFO.json` records source/build commits and validation provenance.

## Validation

This compatibility rebuild changes descriptor metadata only. Application class bytes and every native file, executable mode and timestamp match the validated baseline: 53 JUnit/SDK checks on Windows x64 and 15 native checks per platform. A fresh SDK registration check passed, and every rebuilt ZIP is checked for identity, UTF-8, platform dependencies and absence of upper-build attributes. The unchanged bytecode passed API checks through `IU-263.7307.112` RC, with the internal/deprecated usages recorded in `docs/testing.md`. Physical audio and the wider IDE-product matrix remain separate manual checks.
