# Any Player 0.1.0

Video player, audio player and image viewer for JetBrains IDEs on IntelliJ Platform 2026.1 (261).

Plugin ID: **`me.romanovsky.anyplayer`**. Remove an earlier development installation before switching to this identity.

## Included

- Video/audio playback with seeking, speed, volume and track selection.
- Local paths and direct HTTP(S) media URLs, including explicit transport-stream and extensionless opening.
- Images with Fit, original-pixel inspection, zoom/pan and seekable GIF/APNG/WebP animation.
- Live/full-file spectrograms with stable buffered edges, waveform Follow and separate channels.
- Timestamped hover previews, frame stepping, display-quality scrub frames and replay after EOF.
- MediaInfo properties and copyable reports.

## Downloads

Separate self-contained installation ZIPs are available for **Windows, macOS and Linux**, each on **x86_64 and ARM64**. Choose the running IDE's OS/architecture. Install through **Settings в†’ Plugins в†’ Install Plugin from Disk**, then restart.

All packages belong to this release. A universal ZIP is not required. `SHA256SUMS.txt` covers installers and source bundles; `BUILD-INFO.json` records source/build commits and validation provenance.
